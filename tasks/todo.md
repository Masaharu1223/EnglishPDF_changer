# 利用制限(翻訳の回数制限)と音声系機能の限定公開

## 背景
公開運用のため、無認証で外部の有料API(Claude / ElevenLabs)を叩ける状態を解消する。
`/api/process`・`/api/tts`・`/api/extract` にはセッション確認がなく、`translate` は `chunk` の長さ上限もない。

## 決定事項(2026-10-11 時点でユーザーと合意)
- 制限の単位は**文字数**(Claude・ElevenLabs とも入力テキストの長さに比例して課金されるため)
- チェックは**各APIルート内で、外部APIを呼ぶ直前**に行う(クライアント経由のチェックは回避できる)
- 使用量は Neon の `usage` テーブルで管理し、**1文のSQLで原子的に予約**する(同時リクエストの抜け道を作らない)。失敗時は返却する
- 未認証: **翻訳のみ**。IPごとの小さな枠 + 匿名全体の日次上限の2層(IPごとの枠 ≪ 全体の上限)
- ログイン済み: ユーザーごとの枠 + ログイン済み全体の安全装置(Googleアカウントの量産対策)
- **再生ボタン(TTS)・録音・文字起こしは、試験導入として許可リスト(自分のアカウント)のみ有効**
  - サーバー側(`/api/tts`, `/api/stt`)でセッションの email を許可リストと照合する。UIで隠すだけにはしない
  - 公開時は判定条件を変えるだけにする(ブランチ操作は不要)
- IP はサーバーから見えるグローバルIP。保存時はハッシュ化し、IPv6 は /64 でまとめる
  - Vercel の `x-forwarded-for` はクライアントの公開IPで、外部から付けられた値は上書きされる(公式ドキュメントで確認済み)。`x-vercel-forwarded-for`(同じ値で、手前にプロキシを置いても上書きされない)を先に見る
- **予算**: 自分以外のユーザー全員の利用総額を**月5,000円**に収める。自分(許可リストのアカウント)の利用は予算に含めず、別枠の安全装置だけを置く
  - 費用は Claude Haiku 4.5(入力$1 / 出力$5 per 100万トークン)で、1,000文字あたり約0.55〜1.1円(概算・実測前)。高いほうで計算し、31日で割って**自分以外の全員の合計 14万文字/日**
- 上限(1日・文字数、環境変数で上書き可。未設定や不正な値のときは既定値):

| 環境変数 | 既定値 | 意味 |
|---|---|---|
| `USAGE_LIMIT_ANON_IP_CHARS` | 12000 | 未ログイン・IPごと |
| `USAGE_LIMIT_ANON_TOTAL_CHARS` | 48000 | 未ログイン全体 |
| `USAGE_LIMIT_USER_CHARS` | 30000 | ログイン済み(自分以外)・ユーザーごと |
| `USAGE_LIMIT_OTHERS_TOTAL_CHARS` | 140000 | 自分以外の全員の合計(予算の天井) |
| `USAGE_LIMIT_OWNER_CHARS` | 100000 | 自分(安全装置) |
| `MAX_TRANSLATE_CHUNK_CHARS` | 2000 | 翻訳1リクエストの最大文字数 |
| `FEATURE_ALLOWED_EMAILS` | (空) | 音声・文字起こしと、予算の対象外(owner)になるメールアドレス(カンマ区切り)。未設定なら誰にも許可しない |

  - 環境変数は設定値の保管用。使用量(状態)は Neon の `usage` に置く(インスタンス間でメモリを共有しないため)
  - 変更は Vercel で保存したあと **Redeploy** が必要
- 保険として、Anthropic Console 側で月の利用上限を設定する(コードの制限が破られた場合に請求を止める)
- 日付は UTC で保存し、画面ではタイムゾーン(JST)を明示する(日付・時刻の規約に従う)

  - **適用方法**: `scripts/migrate.mjs` は全ファイルを毎回実行し冪等でないため使わず、所有者ロールで0004だけをトランザクション内で適用した(`usage` が既に存在する場合は何もしない確認つき)。適用後、列・主キー・`app_user` の権限(select/insert/update可、delete不可)、行数0を確認
  - `app_user` 接続での実地確認: 予約SQLが通る(5,000)、上限超過は拒否、`delete` は `permission denied`、ロールバック後の行数0
