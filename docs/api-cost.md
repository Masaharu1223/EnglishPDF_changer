# APIの利用料金と利用制限のしくみ

このドキュメントは、**エンジニアでなくても「いくらかかるのか」「なぜ上限があるのか」が分かる**ことを目的にしています。
要件定義とは別に管理します(料金は見落とされやすく、かつ運営費に直結するため)。

> 最終更新: 2026-10-30 / 為替は 1ドル=150円で仮定 / 数値は実測にもとづく目安で、請求額そのものではありません。

---

## 1. 一言でいうと

- 費用が発生するのは **「英文を日本語訳に変えるとき」(Claude API)** と **「音声を再生するとき」(ElevenLabs)** です。
- 画面を開く、履歴を見る、といった操作では、これらの費用は発生しません。
- 使い放題にすると請求が青天井になるため、**自分以外のユーザーの翻訳費用は、合計で月5,000円以内に収める**よう、1日あたりの利用上限を設けています。

## 2. 何にいくらかかるか

| 機能 | 使うサービス | 料金の決まり方 | 誰が使えるか |
|---|---|---|---|
| 翻訳 | Claude API(Anthropic) | 送った文章と返ってきた文章の「量」に応じた従量課金 | 全員(未ログイン含む) |
| 音声再生(再生ボタン) | ElevenLabs | 読み上げた文字数に応じた従量課金 | 運営者(許可リストのアカウント)のみ |
| データ保存 | Neon(DB) | プランによる(翻訳の量とは別) | ログイン済みユーザー |
| 配信 | Vercel | プランによる(翻訳の量とは別) | - |

このドキュメントは、**従量課金の大部分を占める翻訳(Claude API)**を中心に説明します。DB・配信のプラン料金は、各サービスの契約内容を別途確認してください。

## 3. 翻訳1回あたりの料金

Claude APIは、文字数ではなく **「トークン」**(AIが文章を読む単位。英語なら1単語が1〜2トークン程度)で課金されます。

```
費用(ドル) = 入力トークン × $1 / 100万  +  出力トークン × $5 / 100万
費用(円)   = ドル × 150
```

- **入力**: こちらがAIに送る分(英文+AIへの指示文)。
- **出力**: AIが返す分(日本語訳など)。**単価は入力の5倍**です。

### 実測の例(会話文)
| 文字数 | 実費の目安 |
|---|---|
| 201文字(短い自己紹介) | 約0.3円 |
| 680文字 | 約0.75円 |
| 1,490文字 | 約1.4円 |

→ ざっくり **1,000文字あたり約1円**です。

### 短い文章でも、最低限かかる
AIには毎回、指示文などの「固定の入力」(約740トークン)を送るため、1文字だけの翻訳でも費用はゼロになりません。そのため、アプリ内では **1回の翻訳につき最低500文字分**として数えます。

## 4. 利用制限のしくみ(月5,000円を守るための仕組み)

「使った文字数」を、1日ごと・枠ごとに数え、上限に達したら翻訳を断ります。数える量は次のとおりです。

```
1回の翻訳で数える量 = 大きいほう( 文字数 , 500 )
円に換算すると ≒ その量 × 1.1円 / 1,000
```

(実費の目安が1,000文字あたり約1円なので、少し高めの1.1円で数えて、余裕を持たせています)

### 上限(1日あたり・既定値)
| 枠 | 上限(文字) | 目的 |
|---|---|---|
| 未ログイン・同じ接続元(IP)1つ | 12,000 | 1人が使いすぎないように |
| 未ログイン全員の合計 | 48,000 | 未ログイン全体の天井 |
| ログイン済み・1人 | 30,000 | 1人が使いすぎないように |
| **自分以外の全員の合計** | **100,000** | **月5,000円を守る最終の天井** |
| 運営者(許可リスト)・1人 | 100,000 | 誤操作や暴走への安全装置 |

- 「1日」は世界標準時(UTC)で区切ります。**日本時間の毎朝9:00**にリセットされます。
- 画面には「残り◯文字」を表示します。

### 月の費用の見積もり(自分以外のユーザー)
| 前提 | 計算 | 月額の目安 |
|---|---|---|
| 毎日、上限いっぱい使われた場合(通常の実費) | 100,000文字 × 31日 × 約1.0〜1.1円 / 1,000 | 約3,200〜3,400円 |
| 毎日、上限いっぱい使われ、AIの出力が上限まで伸びた最悪ケース | 100,000文字 × 31日 × 約1.55円 / 1,000 | 約4,800円 |

誰も上限まで使わなければ、実際の費用はこれより低くなります。

## 5. 運営者(許可リスト)のアカウント

- 環境変数 `FEATURE_ALLOWED_EMAILS` に登録したGoogleアカウントだけが、運営者として扱われます。
- 運営者の利用は **「自分以外の合計」には含めません**(月5,000円の枠とは別)。自分の分は、1日100,000文字の安全装置で守ります。
- 音声再生(ElevenLabs)も運営者のみです。1回あたり5,000文字までです。

## 6. 注意点・まだ確定していないこと

| 項目 | 内容 |
|---|---|
| 為替 | 150円/ドルで計算。円安が進むと、円での費用は増える |
| 単価改定 | AnthropicがClaudeの料金を改定すると、見積もりが変わる |
| 日本語以外の文章 | 実測は英文の会話文のみ。専門用語・数字が多い文章では比率がずれることがある |
| 最悪ケース | AIの出力が想定より長くなると、実費が予約(1.1円/1,000文字)を超える可能性がある。そのため、AIの出力の長さに上限(送った文字数の約2倍+256トークン)を設け、合計上限も140,000ではなく100,000文字にした。最悪でも約1.55円/1,000文字で、月約4,800円に収まる |
| 失敗したとき | AIを呼ぶ前に失敗した場合は、数えた分を戻す。AIを呼んだ後に失敗した場合は、費用が発生しているため戻さない |
| 最終的な歯止め | Anthropicのコンソールで、月の支出上限(Spend limit)を設定する(リリース後に実施) |

## 7. 上限を変えたいとき

上限は環境変数で変えられます(コードの変更は不要)。Vercelで値を保存したあと、**Redeploy**すると反映されます。

| 環境変数 | 意味 | 既定値 |
|---|---|---|
| `USAGE_LIMIT_ANON_IP_CHARS` | 未ログイン・IP1つの1日の上限 | 12000 |
| `USAGE_LIMIT_ANON_TOTAL_CHARS` | 未ログイン全員の1日の上限 | 48000 |
| `USAGE_LIMIT_USER_CHARS` | ログイン済み1人の1日の上限 | 30000 |
| `USAGE_LIMIT_OTHERS_TOTAL_CHARS` | 自分以外の全員の1日の上限(費用の天井) | 100000 |
| `USAGE_LIMIT_OWNER_CHARS` | 運営者の1日の上限 | 100000 |
| `USAGE_MIN_CHARGE_CHARS` | 1回の最低課金(文字) | 500 |

変更するときは、月額を次の式で見積もってください。

```
月額(円) ≒ 「自分以外の全員の1日の上限」 × 31 × 1.1 / 1,000   (通常の目安。最悪ケースは1.55で計算)
```
